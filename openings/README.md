# Opening books

`uho-8mvs.epd` is the 8-move UHO book (`8mvs_+90_+99.epd`) from the
[Stockfish book collection](https://github.com/official-stockfish/books), released under CC0.
It is third-party data and is not covered by Nexarch's MIT license. The panel benchmark uses it
so every engine starts from the same balanced positions.
